# 🚀 Skill — Astro Institutional SEO Optimizer (Cloudflare Pages)

## 🎯 Objetivo

Adaptar, estruturar e otimizar conteúdos de websites para projetos desenvolvidos com **Astro**, com foco em:

* Alta performance
* SEO avançado
* Escalabilidade
* Arquitetura orientada a componentes
* Deploy no Cloudflare Pages

---

## 🧠 Contexto do Projeto

Tipo de projeto:

* ✅ Site institucional
* ✅ Blog
* ✅ Múltiplas páginas
* ✅ Projeto em crescimento contínuo

Stack alvo:

* Astro
* Cloudflare Pages
* GitHub (CI/CD)
* Integrações com n8n

---

## ⚙️ Responsabilidades da Skill

### 1️⃣ Estruturação para Astro

Converter o conteúdo recebido em:

* Componentes reutilizáveis
* Layouts
* Páginas
* Coleções de conteúdo

Seguindo:

```
src/
 ├─ layouts/
 ├─ components/
 ├─ pages/
 └─ content/
```

---

### 2️⃣ Arquitetura de Conteúdo

Organizar:

* Página institucional
* Páginas de serviço
* Blog
* Landing pages
* Páginas legais (LGPD, termos)

Criar:

* Slugs amigáveis
* Hierarquia semântica
* URLs SEO-friendly

---

### 3️⃣ SEO Avançado

Gerar automaticamente:

* Title otimizado
* Meta description persuasiva
* Open Graph
* Twitter Cards
* Canonical URL
* Schema Markup

Aplicar:

* Heading structure correta
* Internal linking
* Keyword placement estratégico
* Conteúdo escaneável

---

### 4️⃣ Performance (Core Web Vitals)

Garantir:

* Zero JS desnecessário
* Uso de islands architecture quando necessário
* Imagens otimizadas
* Lazy loading
* Fontes locais
* CSS crítico

---

### 5️⃣ Blog com SEO

Estruturar:

* Coleções de conteúdo
* Markdown ou MDX
* Sistema de categorias
* Sistema de tags
* Paginação
* Posts relacionados

Gerar:

* Índice automático
* Sitemap
* RSS feed

---

### 6️⃣ Integração com Cloudflare Pages

Preparar:

* Build command
* Output directory
* Variáveis de ambiente

Garantir compatibilidade com:

* Edge delivery
* Cache inteligente
* Deploy contínuo

---

### 7️⃣ Integração com GitHub

Configurar fluxo:

* Branch de produção
* Preview deploys
* Versionamento de conteúdo
* Estratégia de commits semânticos

---

### 8️⃣ Integração com n8n

Preparar estrutura para:

* Webhooks
* Automação de conteúdo
* Publicação automática de posts
* Atualização de páginas
* Revalidação de build

---

## ✍️ Regras de Geração de Conteúdo

O conteúdo deve ser:

* Blocos de destaque
